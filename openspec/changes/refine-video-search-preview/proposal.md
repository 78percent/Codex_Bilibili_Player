# Proposal

> 2026-11-16 更新：用户已确认预览并授权正式接入。下文保留原提案范围；当前源码实施状态见 implementation.md 和 tasks.md。

## Why

用户提供的预览截图显示输入框出现粗黑焦点矩形，且输入后热搜、历史与联想同时出现，干扰当前搜索任务。需先收敛独立预览的视觉及状态规则，再由用户确认是否正式接入。

## What Changes

- 输入焦点由输入框粗黑轮廓改为搜索栏轻量强调，保留可辨识的键盘焦点。
- 空输入显示 B站热搜及底部最近搜索；有输入只显示单列联想；提交后显示四列视频结果。
- 最近搜索最多显示10条、最多3行，点击直接搜索，去重并将最近使用的词移至最前。
- 仅持久化搜索词，不写入每次视频搜索结果、页码、选片或滚动快照。
- 保留标准 B站品牌图形、单播放器选片交互；本次仅改预览和文档，正式接入须等待用户确认。

## Capabilities

### New Capabilities

- `video-search`: 视频搜索的输入状态、联想、结果、历史记录、选片与预览确认边界。

### Modified Capabilities

无。当前 `openspec list --specs` 返回无已归档规格；本变更建立该能力的行为基线，不代表功能已经正式接入。

## Impact

- 当前变更对象：聊天内 `video-search-studio.html` 预览及本目录文档。
- 后续接入对象：`src/features/video-search/`、搜索样式、ActivityRail 和共享播放器选片入口；先重新阅读当前文件，保护并行改动。
- 已有实现计划的持久化结果方案被本变更取代；旧源码尚未同步，不将其标记为完成。
- 不引入依赖；不运行测试、lint、类型检查、启动验证或未请求的构建打包。

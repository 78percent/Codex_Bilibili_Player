# JetBrains Mono代码字体

用户指定代码文字使用字体目录内的JetBrains Mono，包括变更预览。普通文本保留Inter和思源黑体，中文代码注释回退思源黑体。

采用已有代码语义定位字体：pre/code标签、差异行、编辑器和终端字体变量；设置中的脚本和环境变量补充textKind标记。不增加文本猜测或新的Markdown解析器。

- [x] 内置JetBrains Mono 2.304正体、斜体可变字体及OFL许可证。
- [x] 为代码区域设置独立字体栈，补充代码设置字段。
- [x] 同步字体来源、设计及实施记录。
- [x] 生产编译、打包1.2.2，交付根目录EXE及桌面快捷方式。

遵守用户要求，不运行测试、lint、类型检查或启动验证。视觉效果由用户打开制品查看。

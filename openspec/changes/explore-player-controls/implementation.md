# 正式接入记录 · 2026-11-16

用户确认原型并授权开工，补充要求字幕选项向下展开。本轮将控件接入真实播放器源码；没有启动应用、运行测试、lint、类型检查、构建或打包。

## 界面与交互

- 聊天内可缩放卡片与右侧窗口继续复用单一 video / dash.js 播放会话，控件不创建第二个播放器。
- 工具栏保持单排：上一条、播放/暂停、下一条、时间、喇叭、弹幕、齿轮。窄容器依次省略总时长、时间、快捷弹幕按钮；弹幕始终可从设置操作。
- 齿轮集中音量、账号实际可用清晰度、0.5 / 1 / 1.25 / 1.5 / 2 五档倍速、字幕与弹幕设置。倍速使用与音量相同的圆形滑块滑杆。
- 字幕、清晰度和字号统一为自定义选择框，列表在触发按钮下方参与正常布局；空间不足由设置面板滚动承载，不再由系统原生选择器翻成上拉。支持方向键、Home/End、Esc 和焦点回到触发按钮。
- 喇叭单击静音/恢复最近的非零音量，悬停/键盘焦点展开竖向音量滑杆，浮层与按钮间保留穿越区域。拖动保持展开，Esc 收起。
- 点击画面播放/暂停；画面滚轮调音量，保留 Ctrl/Meta 缩放。画面焦点支持 Space/Enter、左右 5 秒、上下音量、M 和 D，不拦截设置输入框与滑杆按键。
- 设置开闭、子页进退、列表展开和开关滑块使用短过渡，尊重系统减少动态效果设置。
- 选集入口暂时隐藏，全屏不提供；不改变其他开发场景。

## 数据与状态

- 首页推荐保留当前批次，下一条按批次推进，用完再请求新推荐，上一条回到本次队列。搜索视频重新建立队列；播放位置不跨视频恢复。
- 选片失败显示原因，不静默跳过；导航失败恢复上一有效视频与工具栏，重试继续请求原失败目标。媒体流重建后可重新播放上一有效视频。
- 字幕通过 `/x/player/wbi/v2` 读取轨道，下载对应 JSON 正文，按当前媒体时间显示；无轨道禁用选择，不生成替代字幕。
- 弹幕通过 `/x/v1/dm/list.so` 读取实时 XML 池，渲染滚动、顶部、底部普通文字。Canvas 依媒体时钟定位；支持透明度、字号、滚动区域、速度、密度、类型、颜色和屏蔽词。高级弹幕不执行。
- 音量、倍速、字幕和弹幕偏好保存在应用本地存储；推荐队列只在本次会话保存，账号退出时清空。
- 换片修订号及前端请求清理隔离迟到响应；字幕/弹幕失败单独展示，不阻断视频播放。字幕 URL 仅接受已登记的 HTTPS hdslb 字幕路径，外部正文和弹幕请求不携带账号 Cookie。

## 使用反馈修订 · 2026-11-16

用户反馈音量悬停滑杆消失、弹幕偶尔无法加载，并要求重启默认视频窗口、保留尺寸和上次视频。

定位与修订：

- `main.tsx` 后加载的 `.bili-controls input[type=range]` 与旧浮层输入规则优先级相同，14px 高度覆盖了96px竖向滑杆。提高浮层规则的限定范围，明确最小高度并禁止压缩。
- 弹幕文档说明接口采用 deflate；旧实现直接 `response.text()`，完全依赖 HTTP 自动解压。现读取字节，支持已经解码的 XML、raw deflate 和带封装压缩；主接口请求或格式失败后，仅尝试一次文档列出的 `comment.bilibili.com/{cid}.xml`。换片取消不触发备用请求，HTTP 错误保留状态码。没有现场错误响应，不能断言用户每次偶发失败均由压缩造成。
- 当前视频弹幕关闭再打开复用已加载结果；字幕与弹幕重试分离，避免一次重试重新请求两种资源。
- 新增 `playbackMemory.ts`，按 UID 保存 bvid/cid/进度/归属对话；在选片后、播放过程中、暂停、切片前和退出前写入。恢复重新读取真实视频详情与当前权限，默认暂停，点击播放续播；不保存过期媒体 URL，不自动刷新替换恢复失败的视频。
- 初始宿主改为右侧，启动展开视频与工作区，保留已有 `panelWidth` 和 `videoExpanded`；聊天卡片宽度保存到 `settings.videoCardWidth`。未修改桌面应用外层窗口的尺寸策略。
- 开发脚本原先每次使用随机端口，而 localStorage 按 origin 分离，导致重启无法读取上次前端数据。改为复用上次 `processes.json` 的端口，首次5173，端口占用则报错。独立审阅指出 HTTP 探测可能命中旧服务，已补上启动前的独占绑定检查；该检查仅写入脚本，没有在本轮运行。

独立静态审阅覆盖恢复/退出/账号隔离、历史功能兼容、弹幕与CSS修改；已有 HistoryPlaybackObserver 和搜索选片接口保留。没有运行测试、lint、类型检查、启动、构建或打包，没有提交/推送。修订的运行效果待正常使用确认。

## ADDED Requirements

### Requirement: 默认最大化启动
应用 SHALL 在开发入口与打包入口创建主窗口时最大化，并保留窗口控制功能。

#### Scenario: 启动主窗口
- **WHEN** 用户通过开发 cmd 或打包 exe 创建主窗口
- **THEN** 主窗口以最大化状态显示

### Requirement: 默认收起预览与变更工作区
应用 SHALL 每次初始化时收起右侧预览与变更工作区，不受上次保存的展开状态影响。

#### Scenario: 恢复曾展开的工作区
- **WHEN** 应用恢复上次已展开工作区的本地状态
- **THEN** 工作区保持收起，用户仍可手动展开已有内容

#### Scenario: 首次启动
- **WHEN** 应用没有有效的本地保存状态
- **THEN** 初始工作区保持收起

# Bilibili 登录、账号资料和首次真实播放

状态：用户已授权开始开发；代码已实现，运行验收受阻，2026-11-16。

## Why

现有应用只有 Codex 风格 UI 和空视频窗口。本阶段接通真实 B 站账号、首页首个普通视频与播放，验证这个桌面骨架能够承载实际观看功能。

## What Changes

- 扫码、账号密码、手机验证码三种 B站登录入口，确认账号已绑定手机号；本机保存登录，支持退出。
- 齿轮下方增加真实头像入口，账号菜单进入 Profile，展示真实账号资料。
- 收藏夹、历史和关注仅保留入口，不接业务。
- 获取本软件会话的首页推荐，跳过广告和直播，选取首个普通视频。
- 聊天内可拖动缩放的视频卡片与右侧窗口共用单一播放器，提供有声播放、暂停、拖动、音量与实际可用清晰度切换；待运行验收。
- 按用户所选路线 A 集中封装社区主站接口；不申请官方 OAuth 或嵌入官方播放器。

## Impact

修改范围集中在 Electron B 站服务、preload 的专用接口、前端账号/Profile/视频模块，以及对应入口与样式。其余虚构开发场景继续本地模拟。

本阶段用户最新请求将真实 B 站接入和两类验收列为允许范围。设计批准后同步 AGENTS.md 与 openspec/config.yaml 的旧阶段约束：仅允许布局与视频功能验收，继续禁止 lint、类型检查及额外测试。

详见 design.md、tasks.md 与 implementation.md。用户已批准实施；本文件不表示实际播放已成功。

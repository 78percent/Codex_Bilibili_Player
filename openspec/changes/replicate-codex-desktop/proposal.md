# 完整 Codex 前端复刻

## Why

为后续 Bilibili 播放器建立与当前 Codex Windows 桌面版一致的前端基础。旧项目删除重建；内容扩展必须建立在独立、模块化的页面和交互之上。

## What Changes

- 从本机安装包进行 REA 静态研究，记录组件、样式、动画来源。
- 重建完整窗口框架、会话、项目、自动化、技能、插件、审查、工作区和设置页面。
- 用四组虚构开发项目连接消息、工具调用、文件、差异、终端、任务和 PR 状态。
- 实现流式预设场景和本地持久化。
- 视频模块留空。

## Capabilities

- `desktop-shell`: 视觉、页面与本地交互。
- `scenario-simulation`: 开发场景、过程与持久化。

## Impact

目标目录为 `D:\Codex_Bilibili_Player`，旧目录移入回收站后重建。设计已批准，前端已实现，Windows x64 便携 EXE 已生成并交付。构建器退出码 0；运行与视觉验收未执行。不连接真实后端，不执行用户禁止的测试。

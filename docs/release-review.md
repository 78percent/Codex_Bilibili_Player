# 开源与发布检查 · 1.4.0

日期：2026-11-19。检查当前源码、依赖、公开文件边界与 Windows x64 发布产物，不把“检查通过”表述为所有电脑和账号均可用。

## 公开边界

- 自有代码采用 MIT，字体、依赖和服务标识各自保留许可；第三方声明同时随便携程序分发。
- 个人截图、开发流水账、OpenSpec 本地工作记录、会话预览路径、原始桌面软件研究输出只留在维护者本地。
- 公开文档保留 README、使用兼容、隐私、架构、贡献、安全、资源来源和正式版本记录。
- 来自第三方桌面安装包的旧应用图标已替换，未使用的标识已移除。
- 按维护者决定保留旧 Git 历史与旧 Release；这不等于清除历史个人信息、第三方素材、他人克隆或缓存。

## 修正与检查状态

- 固定最小窗口尺寸可能超过高缩放屏幕的工作区：主窗口、官方登录和主页窗口统一限制初始尺寸。
- 旧播放器测试夹具缺少分 P 字段：补齐当前接口结构；新增搜索参数、相关 UP 映射和窗口尺寸回归覆盖。
- 原 npm 镜像无安全公告接口：仓库指定官方 npm registry，发布审计不把镜像的错误响应当作零漏洞。
- 退出或 UID 变化时关闭官方主页窗口，避免旧页面与新账号会话混用；普通资料刷新不关闭窗口。
- `npm ci` 完成；Electron 运行文件需另行执行上游安装脚本，README 和贡献指南已补充。
- `npm test`：20/20 通过，包括模拟接口的搜索条件切换、UP 显隐与返回恢复；`npm run typecheck` 通过。
- 官方 npm 全依赖审计：0 项已知漏洞；用限定版本范围的 override 修正构建链 minimatch 公告。
- 公开索引扫描：261 个文件未命中所定义的个人路径、凭证和内部资料规则；规则扫描不保证发现所有秘密，不扫描旧历史。公开 Markdown 相对链接完整。
- 最终 ASAR 含 1.4.0 新模块，未包含所检查的内部目录和会话文件；3 份字体许可、73 个许可/清单文件随包收录。上游许可原文保留，包括空白格式。
- `npm run package` 成功；保留前端单个文件超过体积阈值的提示，不影响这次构建完成。
- Windows 11 x64 最终 EXE 的中文/空格路径、空白用户目录、移除 Node.js 路径的隔离启动通过；渲染、重载、沙箱桥接、CSP、H.264 能力、IPC 白名单和访客门禁通过，无记录到的渲染错误。
- 匿名热搜、联想、排序/时长筛选搜索、相关 UP 与二维码接口均成功；数量分别为 10、10、20、1，二维码仅检查 HTTPS 并取消。没有真实账号写操作。
- 产物大小和 SHA-256 见[版本记录](releases/1.4.0.md)，以 Windows x64 预发布提供。

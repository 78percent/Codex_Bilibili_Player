# 开发结构

Electron 主进程负责窗口、B站账号、WBI 请求、媒体中转与写操作；React 渲染进程只通过受限 IPC 调用业务操作。生产窗口启用沙箱与 context isolation，禁用 Node integration，限制导航、权限和内容来源。

| 目录 | 责任 |
| --- | --- |
| `electron/bilibili/` | 账号、搜索、UP 资料及内容、历史、字幕弹幕与媒体中转 |
| `electron/window.cjs`、`main.cjs` | 主窗口、单实例与生命周期 |
| `src/features/video/` | 单一播放会话、聊天内与右侧播放器、分 P 和快捷键 |
| `src/features/video-search/` | 搜索、联想、排序、时长/分区筛选和相关 UP |
| `src/features/uploader/` | 主页、投稿、动态、合集、关系与会话内浏览记录 |
| `src/features/history/`、`account/` | 观看记录与登录界面 |
| `src/scenarios/`、`state/` | 本地演示场景和状态；不包含真实 AI 后端 |

搜索的视频排序和筛选由 B站处理；相关 UP 只在综合排序、全部时长、全部分区的第一页采用综合响应的 `bili_user` 模块，保持原顺序、最多两个，不从视频作者推算。相关 UP 失败可单独重试，不清空视频结果。

搜索和主页共享最多 12 项页面资源缓存，浏览历史最多 24 条地址。地址记录关键词、页码、排序、筛选、滚动和焦点；页面正文不持久保存。账号变更隔离缓存。最近搜索只持久保存去重后的关键词。

聊天卡片和右侧视频窗口共用一个播放会话。分 P 切换更新 CID、字幕、弹幕和观看进度；左右短按跳转 5 秒，上下短按或长按调整播放音量，不操作系统音量。

本地开发日志、OpenSpec 工作记录、原始反向研究输出、会话预览路径和个人截图不属于公开文档。仓库仅维护面向使用者与贡献者的说明、资源来源及版本记录。

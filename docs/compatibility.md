# Windows Release 兼容说明

下载 Release 附件中的 `*-x64.exe`，不要把 GitHub 的 `Source code` 压缩包当作安装程序。程序自带 Electron/Chromium，不需要另装 Node.js、Git、Python 或 WebView2。

## 平台范围

| 环境 | 当前范围 |
| --- | --- |
| Windows 10 / 11 x64 | 当前发布目标；推荐仍获得系统安全更新的 Windows 版本。具体实测范围见对应 Release。 |
| Windows 7 / 8 / 8.1、32 位 Windows | 不支持当前 Electron 运行时。 |
| Windows ARM64 | 没有原生 ARM64 产物；x64 模拟运行不在已验证范围。 |
| macOS / Linux | 没有对应发布产物，不承诺源码直接打包可用。 |
| 中文或含空格的目录 | 发布检查覆盖；不依赖开发者盘符、用户名或开发工具。 |
| 高 DPI、低分辨率、多屏 | 需按具体缩放与工作区大小判断；窗口最低尺寸会受到可用工作区限制，分栏仍可能拥挤。 |
| 企业电脑 / Windows S 模式 | 管理策略可能阻止未签名程序、临时目录执行或本机回环端口；不能承诺可用。 |

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| SmartScreen、杀毒软件或企业策略阻止启动 | 当前 EXE 未做代码签名。只从本仓库 Release 下载，并核对 `SHA256SUMS.txt`；不建议关闭安全软件。企业电脑应联系管理员。哈希只能确认下载一致性，不是作者身份或安全认证。 |
| 双击后需要等待 | 便携程序先解压运行时。临时目录需要可写且有足够空间；首次启动可能更慢。 |
| 提示无法初始化播放服务 | 本机随机回环端口或文件访问被阻止，或程序不完整。核对哈希和组织策略后重试。 |
| 界面正常，视频黑屏或解码失败 | 播放只支持服务端提供的 H.264/AAC DASH；HEVC/AV1-only、DRM、部分会员/付费内容不可用。Windows N、远程桌面和特定 GPU/驱动需单独验证；可先更新系统媒体组件与显卡驱动。 |
| 登录正常，但搜索、主页或播放失败 | 社区网页接口、WBI 签名、风控、系统时间、网络及地区限制都可能影响请求。完成官方验证、校准系统时间后重试；账号未绑定手机号或绑定状态未知会阻止播放和写操作。 |
| 某些视频加载失败 | 所选 CDN 不可达时不会逐一切换所有备用 CDN；重新取流可能恢复，但不保证。只使用能访问 B站相关域名的网络，保留组织的 TLS 校验策略。 |
| 密码/短信窗口没有切到预期页签 | 官方页面结构可能变化，可以在官方窗口手动选择；项目不接管密码输入。 |
| 换电脑后要求重新登录 | 会话加密绑定本机环境；重新登录即可，不要复制或分享会话文件。 |
| 删除 EXE 后记录仍存在 | 数据在 AppData，见[隐私说明](privacy.md)。 |
| 下载新版仍看到旧窗口 | 应用是单实例，先关闭旧窗口再启动新版。没有自动更新；不要仅覆盖仍在运行的程序。 |

发布检查不能替代第二台实体电脑、真实登录后的持续播放和所有网络/GPU 的验收。请在反馈中提供版本号、Windows 版本、CPU 架构、缩放比例和脱敏错误信息，不要提供 Cookie、二维码或整个 AppData。

# 视频搜索实现计划

**目标：** 左侧小电视打开 Codex 风格搜索弹层，真实 B 站热门词、联想词与四列视频结果，点击后在当前聊天播放，重新打开恢复操作结果。

**架构：** Electron B站客户端负责接口和选片；独立 video-search 模块负责搜索状态、本地保存、弹层与卡片；复用 VideoProvider 的单一播放会话。

**约束：** 不运行测试、lint、类型检查、启动验证或未请求的构建打包。保留当前未提交修改。仅改本次搜索所需内容，截图中的设置删除及头像调整不属于本次文字请求。原聊天搜索保持独立。

**方案：** 采用原生 React 弹层并复用主进程请求，比嵌入官网搜索页更适合四列布局、状态恢复和当前聊天播放；不建立第二播放器。沿用已有字体、颜色、间距和 REA 静态资料。

**实现判断：** 用户已确认热门指热搜词；输入时展示 B站联想，回车或点击词条才搜索。每页20条，四列，分页；按账号保存输入、已提交词、结果、页码、滚动位置。新聊天选片时创建空聊天并展示播放器。搜索允许访客签名请求；播放沿用现有登录及播放资格限制。

- [x] 界面：独立搜索状态、弹层、四列视频卡片、左侧小电视入口与样式。
- [x] 静态阅读变更，记录限制；不执行任何运行验证。

**静态审阅重点：** 快速切换关键词和分页的旧响应；账号切换；关层及重新打开；选片竞争；无当前聊天；图片/标题规范化；焦点返回与 Escape。

# 本地数据与网络

程序直接请求 B站 API、登录页面和内容 CDN。没有项目自建的账号中转服务器，也没有配置遥测或崩溃上传服务。第三方网页仍按其自身规则处理数据。

| 数据 | 保存或发送方式 |
| --- | --- |
| 登录 Cookie | 主进程隔离会话；用 Electron safeStorage 加密保存为 `bilibili-session.bin`。Windows 用户或系统环境变化后可能需要重新登录。 |
| 密码、短信验证码 | 在 B站官方网页窗口输入；应用代码不读取输入内容。 |
| 搜索词、观看记录、播放位置 | 本机 localStorage 明文保存，按账号分键；退出登录后仍保留。 |
| 聊天、演示工作区和布局 | 应用级 localStorage 明文保存，不按 B站账号隔离。聊天没有接入真实 AI 服务，不要填入密码或业务机密。 |
| 观看进度 | 播放期间同步到 B站，会影响服务端观看历史。 |
| 关注、取消关注、动态点赞 | 由用户点击后发送到 B站，属于真实账号操作。 |
| 媒体流 | 经 `127.0.0.1` 随机端口转发，临时 URL 包含随机令牌；CDN 请求不携带账号 Cookie。不要分享完整媒体 URL。 |

正式版数据目录是 `%APPDATA%\CodexBilibiliPlayer`，开发版是 `%APPDATA%\CodexBilibiliPlayer-Dev`。便携版表示免安装，不表示数据跟着 EXE 保存。删除 EXE 不会删除这些目录；退出账号也不等于清除全部本地记录。

需要移除本机数据时，先退出账号并完全关闭应用，在资源管理器中确认上述准确目录，再自行备份或删除对应目录。这会移除该目录内所有账号的本机记录和布局。不要把旧目录直接交给他人，也不要上传到问题报告中。safeStorage 无法防御同一 Windows 用户下的恶意程序或管理员访问。

安装包按文件清单收集前端、主进程、依赖、字体和许可，不收集开发者 AppData。发布检查使用独立的空白用户目录；不把开发者的登录会话打进 EXE。

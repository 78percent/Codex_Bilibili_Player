# 1.4.0 发布记录

Windows x64 便携预发布版。下载见 [GitHub Release](https://github.com/78percent/Codex_Bilibili_Player/releases/tag/v1.4.0)。

## 变化

- 增加分 P 选集；播放器左右短按跳转 5 秒，上下短按和长按调整播放音量。
- 增加搜索排序、时长与分区筛选；默认首屏采用 B站返回的最多两位相关 UP。
- 搜索浮层内浏览 UP 主页、投稿、动态、合集、关注与粉丝，复用真实关注及动态点赞操作。
- 搜索与主页前进/后退保留条件、页码和位置，按需分页并限制会话缓存大小。
- 主窗口、官方登录窗口和官方主页窗口的初始尺寸受当前可用显示工作区限制。
- 自有代码采用 MIT；替换原第三方桌面图标、补齐依赖许可，个人截图和内部开发记录不再进入新版源码。

## 下载与数据

下载 `Codex-Bilibili-Player-1.4.0-x64.exe`，无需开发工具。EXE 未签名，首次运行会解压；核对同版本 `SHA256SUMS.txt`。数据保存在 AppData，升级不清除现有数据，请先关闭旧窗口再启动新版。

完整平台范围见[兼容说明](../compatibility.md)，数据保存与真实账号操作见[隐私说明](../privacy.md)。

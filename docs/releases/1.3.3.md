# 1.3.3 发布记录

日期：2026-11-18。Windows x64 便携预发布版。

## 下载

下载附件 `Codex-Bilibili-Player-1.3.3-x64.exe`，双击运行。不需要安装 Node.js、npm 或 Git；`Source code` 不是可直接运行的程序。首次启动需要解压运行文件。

游客可以使用热搜、联想和视频搜索；播放需要登录 B 站并通过账号手机号绑定校验。扫码在应用内完成，密码与短信登录使用 B 站官方窗口。

## 变化

- 修改搜索词时保留面板高度和上一批联想，避免收缩闪烁；缩短输入等待时间，复用缓存并合并重复请求。
- 根据窗口高度请求 6–20 条联想，实际数量由 B 站接口决定。搜索框内使用固定 21px 的小电视动画，请求期间变为粉色。
- 完善按账号保存视频与播放进度、重开后暂停续播，以及播放器加载状态。
- 改进弹幕解析、回退与缓存处理，保留聊天卡片与右侧窗口共用播放会话。
- 调整观看历史快捷卡片与管理窗口的尺寸，空记录和加载时保持展开高度。
- 开发启动入口可以唤回已有窗口，并在核对进程记录后清理本项目遗留的 Vite 进程。
- 移除未接入实际功能的通用设置页面，侧栏齿轮保留占位；旧设置页状态可正常恢复至首页。
- 更新下载、启动、数据保存位置与功能边界说明。

# 1.3.0 发布记录

日期：2026-11-16。用户在本轮明确授权测试、打包及上传 GitHub，覆盖之前的“不运行测试”限制。

## 主要变化

- 接入视频搜索、账号观看历史与进度同步，完善播放器控件、字幕与弹幕设置。
- 保留聊天内视频和右侧视频共用一个播放会话。
- 修复媒体地址跨视频复用、退出登录清理及异步取消、历史缓存刷新和启动错误处理。
- 拆出窗口管理、CDN 地址策略及状态持久化模块；补充生产 CSP 和窗口权限。
- Electron 从 36.9.5 升至 **45.3.3**，开发和打包统一使用 `node_modules/electron/dist`；补齐 React/React DOM/二维码类型声明，修复场景数据和消息类型错误。
- 支持标准 `--user-data-dir=<绝对路径>` 参数，验证时使用独立的空白数据目录。

# Security and privacy

Do not post cookies, QR login links, account databases, signed media URLs,
API keys, or complete application data directories in public issues.

For a suspected vulnerability, use GitHub's private vulnerability reporting
if the repository offers it. If no private channel is available, open a
minimal issue requesting a private contact without including the exploit
or sensitive data. Ordinary issues can include the application version,
Windows version, display scale and a redacted error message.

Only the most recent prerelease is targeted for fixes. Older releases are
retained as historical downloads, without a maintenance guarantee. There
is no automatic updater; download a newer release when a fix is published.

See [local data and network behavior](docs/privacy.md),
[compatibility](docs/compatibility.md), and the dated
[release review](docs/release-review.md). A source review or a passing test
suite is not a guarantee that third-party services or every PC will work.
